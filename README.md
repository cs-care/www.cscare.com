# CSCare, Inc.

A single static contact page. No dependencies or build step.

Open `index.html` in a browser to preview. Edit that file to update the details.

## Publish with a new GitHub account

1. Create a public repository named `cscare` in your new account.
2. Upload `index.html` to the repository's `main` branch.
3. Open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, then **main** and **/ (root)**, and save.
4. Wait for deployment and use the site link shown in Pages settings, normally `https://YOUR-USERNAME.github.io/cscare/`.

GitHub Free supports Pages from public repositories. The provided `github.io` address includes HTTPS and requires no domain purchase. Hosting does not provide an email inbox; the email link opens the visitor's email app.

Documentation: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
